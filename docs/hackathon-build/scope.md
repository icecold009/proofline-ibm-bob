# Scope

## Project

Proofline is a deterministic release-evidence assistant for AI builders.

## Time budget

The event provides a 48-hour build window. The target is a reliable MVP early
enough to leave time for Bob evidence, demo recording, and submission materials.

## Core user journey

1. The builder imports one change request.
2. The builder loads one evidence manifest.
3. Proofline classifies claims by evidence class.
4. Proofline runs only known local checks.
5. The builder sees what is proven, simulated, unverified, or blocked.
6. The builder exports a release brief.

## Cut list

Authentication, teams, multi-repository support, CI/CD integrations, live
provider orchestration, autonomous editing, and generalized chat are cut to
protect the demo.

## Wow moment

Proofline catches a claim that says production synchronization is live while
the supplied evidence proves only local tests and simulation.
