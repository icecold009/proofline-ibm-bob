# IBM Bob 2.0 Hackathon guidance

Last checked: 2026-09-20.

This document separates current published guidance from items that are not yet
visible on the event page. It is intentionally conservative.

## Current event facts

- Event: IBM Bob 2.0 Hackathon.
- Format: online.
- Build window: September 25–27, 2026; 48 hours.
- Participation: solo or team.
- Prize pool: 10,000 USD.
- Registration: before the kickoff stream.

Source: https://lablab.ai/ai-hackathons/ibm-bob-2-hackathon

## Platform submission guidance

The lablab guide says a complete submission needs a working online prototype,
a video presentation, and a pitch deck. The general AI-hackathon guide also
describes a public GitHub repository, public demo URL, PDF deck, and a pitch
video of no more than five minutes.

Sources:

- https://lablab.ai/guide
- https://lablab.ai/guide/ai-hackathons

## IBM Bob operational guidance

IBM's Bob hackathon guide says:

- IBM Bob IDE is required and must be a core component.
- Bob Shell is optional.
- Relevant Bob task-session reports must be exported for judging.
- Screenshots and exported task histories belong in a bob_sessions folder.
- Credentials and API keys must be removed before public repository upload.
- Do not use company-confidential data, client data, personal information, or
  social-media data.
- Public web data must be permitted for the intended use and its sources kept.

Source:

https://watsonx-hackathons-2026.s3.us.cloud-object-storage.appdomain.cloud/Lablab-IBM-Bob-hackathon-guide-May-2026.pdf

That PDF is sponsor guidance for the Bob hackathon environment and is dated
May 2026. Re-check the September kickoff materials for superseding details.
