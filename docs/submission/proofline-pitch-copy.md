# Proofline pitch deck copy

Seven-slide 16:9 deck. Updated 2026-09-27 using the checked-out feature commit and a live synthetic hosted-demo check.

1. **Proofline — Evidence before release.** A local report that shows what a software change actually proves.
2. **Release claims need evidence.** A local pass does not prove a hosted integration, provider response, or production readiness.
3. **One manifest, an evidence brief.** Validate one bounded evidence manifest, derive each claim status, and return a self-contained JSON, Markdown, or HTML report with evidence class, limitation, and next action.
4. **Three outcomes stay distinct.** A passing result that was declared but not run stays conditional. Synthetic fixture evidence stays simulated. A claim without hosted evidence stays unverified.
5. **Checks run only through a fixed allowlist.** The separate run-check command uses a known registry ID. Report generation does not execute checks, unknown IDs are blocked, and the demo calls no external AI provider.
6. **Built with IBM Bob IDE.** Bob supported repository-aware development. The deck records 106 local verification tests and local-browser review of all three synthetic states. Redacted Bob history and its summary screenshot are in the repository.
7. **What remains to prove.** The hosted demo showed a live synthetic case remaining conditional; no commands ran. Provider behavior, private-data protections, and production readiness remain unverified.
