# Demo narrative

## Opening

AI can write the change. Proofline answers whether you can responsibly claim it
shipped.

## Three-minute flow

1. Show a synthetic release claim: provider-backed synchronization is live.
2. Load the change request and evidence manifest.
3. Show local tests as proven, simulated telemetry as simulated, and missing
   hosted/provider evidence as unverified.
4. Open the next-check panel. It proposes only the bounded checks that are
   actually available.
5. Export the Markdown release brief.
6. Open bob_sessions and show the repository-aware Bob work that produced the
   implementation.
7. Close by explaining that Proofline makes AI-assisted shipping faster without
   confusing confidence with evidence.

## Visual proof points

- one claim moving from ambiguous to classified;
- one simulation explicitly prevented from becoming production proof;
- one exported report with evidence ownership;
- one Bob task summary and one redacted task-history export.
